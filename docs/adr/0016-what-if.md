# ADR-0016 — What-if без записи и с проверяемым обратным счётом

Дата: 2026-09-23. Статус: принято.

`whatif` использует неизменённое ядро `calc/scenarios.py` и отчётные функции economics. `cost_multiplier` и зимнее удорожание не умножают финансовые статьи; `financial_share_override` добавляется к фиксированным финансовым расходам. Повторяемые множители применяются последовательно, округление после каждого. Sensitivity сравнивает прибыль при ±step, сортирует по модулю изменения, одинаковая чувствительность имеет одинаковый ранг.

Goal-seek использует линейную замкнутую форму, округляет множитель до 6 знаков HALF_UP и проверяет прибыль полным ядром; ненулевой остаток показывается. `whatif` не создаёт сценарии и не пишет в БД. Пресеты сохраняются только через существующую команду `scenario`. Сдвиг графика и пересчёт зимних затрат по новым датам — отдельная задача.
