# ADR-0009: НДС в расчёте прибыли

## Контекст
Сравнение выручки без НДС с затратами с НДС искажает прибыль организации на ОСНО.

## Решение
Прибыль сравнивает выручку и затраты без НДС. `gross` приводится к net по датированной ставке `reference_rates/VAT_RATE`; `net` используется как есть; `unknown` даёт явное предупреждение. Режим поставщика без вычета входного НДС оставлен параметром модели для следующего этапа.

## Последствия
Ставки не зашиты в формулах. При смене режима налогообложения меняется политика допустимости входного НДС, а не арифметика выручки.
