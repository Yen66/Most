# ADR-0003 — Реальные документы не хранятся в Git

## Контекст
Исходные ведомости, графики и иные документы могут содержать коммерческие и идентифицирующие данные. Бинарные XLSX также плохо ревьюятся и текущим коннектором не должны передаваться обходными путями.

## Рассматриваемые варианты
1. Хранить реальные документы в репозитории.
2. Хранить обезличенные бинарные копии.
3. Хранить только текстовые обезличенные данные и детерминированный генератор XLSX.

## Решение
Выбран вариант 3. В Git допускаются `scripts/make_fixtures.py` и `tests/fixtures/data/*.json`. Сгенерированные XLSX создаются в `tests/fixtures/generated/`, который игнорируется Git. Общий `*.xlsx` остаётся в `.gitignore`; исключений для фикстур нет. CI проверяет всю историю на `.xlsx`, `.xls`, `.pdf`, `.docx`, `.env` и `data_raw/`, а индекс — на бинарные расширения.

## Последствия
Тестовые данные ревьюятся как текст, реальные документы не публикуются, а приёмка остаётся воспроизводимой. Любое попадание бинарного документа в историю считается ошибкой и не обходится исключением CI.
