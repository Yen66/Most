# ADR-0010: Категории затрат и производственная себестоимость

## Контекст
Исключение `other` из себестоимости позволило бы реальной затрате исчезнуть из прибыли и точки безубыточности.

## Решение
`costs_production` включает `direct`, `indirect`, `other`. Только `financial` считается отдельно как фиксированная сумма и/или доля выручки.

## Последствия
Каждая актуальная затрата учитывается ровно один раз. `other` выдаёт предупреждение, но не исключается из денег.
