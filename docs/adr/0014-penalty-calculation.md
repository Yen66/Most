# ADR-0014 — Неустойка с заказчика

Решение от 23.09.2026. Ст. 34 ч. 5 44-ФЗ: пеня = сумма
`долг × ключевая ставка × календарные дни / 300`.
Округление `Decimal(0.01), ROUND_HALF_UP` один раз на сегмент.
Для закрытого оплатой сегмента используется ставка на дату оплаты,
для открытого — на дату отчёта. История смен ставок выводится справочно,
но периодная нарезка по ставкам не входит в формулу.
`--rate-date` позволяет сценарно выбрать дату ставки.

Нормативного потолка нет. Ограничение применяется только если
`penalty_cap_pct` заполнен в активной версии договора;
без него выводится предупреждение, в том числе о возможном
снижении по ст. 333 ГК РФ. Пени не храним в отдельной таблице:
это производная величина от версионируемых обязательств,
контракта и датированного каталога ставок.
