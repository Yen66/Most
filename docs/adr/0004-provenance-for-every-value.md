# ADR-0004: Происхождение для каждого импортированного значения

## Контекст
Для проверки расчёта недостаточно знать итог: нужно восстановить документ, лист и ячейку, из которой пришли объём, цена и стоимость.

## Рассматриваемые варианты
1. Хранить только ссылку на документ.
2. Хранить источник на уровне строки.
3. Хранить `ValueSource` и `ValueRef` до конкретной ячейки.

## Решение
Документ получает SHA-256. Для каждого импортированного `WorkItem` создаются ссылки происхождения на объём, цену и стоимость с листом, строкой и адресами ячеек.

## Последствия
Любое значение можно трассировать до источника. Цена — дополнительный объём записей в БД, принимаемый ради аудируемости.
