# ADR-0002: Один репозиторий для фундамента

## Контекст
Фундамент включает импорт, домен, хранение, расчёт выручки, CLI, миграции и тесты. Разделение этих частей по нескольким репозиториям усложнило бы атомарную приёмку пути «файл → база → расчёт → отчёт».

## Рассматриваемые варианты
1. Отдельные репозитории по слоям.
2. Один репозиторий с пакетами внутри `src/construction_os`.

## Решение
Использовать один репозиторий `Yen66/Most` для текущего фундамента.

## Последствия
Изменения схемы, импортёров и тестов проверяются одним CI. Границы пакетов контролируются тестами импортов, а не физическим разделением репозиториев.
