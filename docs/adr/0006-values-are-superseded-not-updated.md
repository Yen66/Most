# ADR-0006: Значения заменяются новой версией, а не перезаписываются

## Контекст
Для аудита необходимо видеть, какое значение действовало до исправления и почему оно изменилось. Повторный импорт того же документа не должен создавать дубликаты.

## Рассматриваемые варианты
1. Обычный `UPDATE`.
2. Удаление и повторная вставка.
3. `supersede` с периодом действия; повтор того же SHA-256 — пропуск.

## Решение
Версионируемые значения заменяются через `supersede`: старая строка получает `valid_to`, новая — `valid_from`, связь и причину. Прямые `update/delete` запрещены. Повторный импорт документа с тем же `(company_id, sha256)` пропускается без создания новых позиций.

## Последствия
История не теряется, импорт идемпотентен. Если в будущем потребуется повторно интерпретировать тот же бинарный файл новой версией парсера, понадобится отдельное решение о версии импорта.
