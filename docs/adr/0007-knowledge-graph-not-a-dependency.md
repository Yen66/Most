# ADR-0007 — Knowledge graph не зависимость

Рассматривался `deeplethe/utopia` (Apache-2.0, Rust, v0.1, молодой проект, LLM-экстракция фактов).
В фундамент не включается: LLM-экстракция не является основанием для расчётов до копейки.

Берём идеи: provenance, период действия, supersede вместо перезаписи, журнал подтверждений.
Будущая интеграция — только read-only сервис поверх нашей БД.

Повторная оценка: версия >=1.0 либо rollback миграций; main; SECURITY/audit; benchmark 100k документов;
backup/restore; точность на русскоязычных документах; сверка чисел с детерминированным парсером;
локальная модель; кириллица/кодировки; правовая оценка LLM-обработки документов госконтрактов.
