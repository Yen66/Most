# ADR-0007: Граф знаний не является зависимостью фундамента

## Контекст
Текущая задача — детерминированный импорт, хранение, сверка и расчёт выручки. Граф знаний не нужен для прохождения приёмочного пути и добавил бы новую зависимость.

## Рассматриваемые варианты
1. Включить графовую БД в фундамент.
2. Моделировать связи обычными внешними ключами и provenance.

## Решение
Использовать SQLAlchemy-модель и явные связи `Document → Source → ValueRef → Entity`. Графовая технология не подключается.

## Последствия
Стек остаётся закрытым. Если позднее появится доказанная задача графового обхода, решение принимается отдельным ADR и не меняет текущие денежные формулы.
