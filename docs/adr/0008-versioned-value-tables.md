# ADR-0008: Версионирование изменяемых значений

## Контекст
Договоры, объекты, позиции ВОР, строки графика, затраты и сценарии меняются после импорта. Прямой UPDATE уничтожает историю.

## Варианты
1. UPDATE на месте. 2. Перепривязка всех потомков. 3. Новая версия родителя; потомки остаются на исходном id, чтение учитывает цепочку `superseded_by`.

## Решение
Выбран вариант 3. Версионируются `contracts`, `objects`, `work_items`, `schedule_tasks`, `cost_entries`, `scenarios`. `reference_rates` уже имеет период действия. Потомки не переписываются: актуальный объект собирает данные по цепочке предшественников.

## Последствия
История ссылок не искажается массовыми UPDATE. Запросы актуального объекта обязаны учитывать lineage и `valid_to IS NULL`. Замена выполняется транзакционно через repository `supersede` и журналируется.
