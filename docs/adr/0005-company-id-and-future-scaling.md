# ADR-0005: company_id присутствует во всех таблицах данных

## Контекст
SaaS и роли отложены, но схема не должна требовать миграции всех данных при появлении нескольких компаний.

## Рассматриваемые варианты
1. Добавить `company_id` позже.
2. Добавить `company_id` сейчас только в часть таблиц.
3. Добавить `company_id UUID NOT NULL` во все tenant-таблицы.

## Решение
Все tenant-таблицы имеют `company_id UUID NOT NULL` и индекс. Исключения: `companies`, `reference_rates` и глобальный канонический `cost_articles`. Третье исключение принято ADR-0011.

## Последствия
Репозитории tenant-таблиц фильтруют по `company_id`. Обоснование глобального справочника затрат и будущих расширений — ADR-0011.
