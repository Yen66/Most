# ADR-0005: company_id присутствует во всех таблицах данных

## Контекст
SaaS и роли отложены, но схема не должна требовать миграции всех данных при появлении нескольких компаний.

## Рассматриваемые варианты
1. Добавить `company_id` позже.
2. Добавить `company_id` сейчас только в часть таблиц.
3. Добавить `company_id UUID NOT NULL` во все tenant-таблицы.

## Решение
Все таблицы данных имеют `company_id UUID NOT NULL` и индекс. Исключения: `companies` — сама является корнем компании; `reference_rates` — глобальный датированный справочник нормативных ставок. Эти два исключения исчерпывающие.

## Последствия
Репозитории tenant-таблиц обязаны фильтровать по `company_id`. Функциональность биллинга, ролей и полноценной мультитенантности не добавляется.
