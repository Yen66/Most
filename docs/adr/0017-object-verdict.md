# ADR-0017 — Вердикт по объекту

Дата: 2026-09-23. Статус: принято для INGESTION-1; пороги пересматриваются владельцем.

- Сетка торгов: 0%, 5%, 8%, 10%, 15%, 20%, 22% и дополнительное снижение из активной версии договора. Стоимость каждой позиции умножается на (1−k) и округляется до копейки; затем суммы складываются.
- НДС: сплит выполняется один раз на уровне объекта после суммирования позиционно округлённых сумм. Это соответствует сноске ВОР о пропорциональном снижении и сохраняет исторические эталоны.
- Полнота: ровно шесть отдельно показываемых нормативных рисков WINTER, TEMP_FAC, TRAFFIC, MOB, DRAIN, LAB_CONTROL; остальные отсутствующие статьи перечисляются отдельно. Суммы отсутствующих статей не оцениваются без исходных данных.
- Светофор — продуктовое правило для маржи прибыли до налога: ≥10% «ВХОДИТЬ», от 3% до 10% «ОСТОРОЖНО — запас тонкий», <3% или прибыль ≤0 «НЕ ВХОДИТЬ». Это пороги интерфейса, а не юридическое или инвестиционное заключение; владелец вправе их пересмотреть.
- При отсутствии затрат светофор не показывается; вывод «вердикт неполный: нет данных по затратам». Никакие «средние по отрасли» не подставляются.
- Вердикт только читает данные, сохраняет tenant-изоляцию и использует активные версии договора, работ и затрат.
