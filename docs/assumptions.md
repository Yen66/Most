# Принятые допущения

## Репозиторий
Подключённый GitHub предоставляет приватный `Yen66/Most`, но не предоставляет действие создания/переименования
репозитория. Работа ведётся в ветке `feat/foundation`; это отклонение от требуемого имени `construction-os`
фиксируется, а не скрывается.

## Реальные фикстуры
В беседе доступны исходные XLSX с теми же контрольными значениями, но прямой перенос бинарных вложений в GitHub
через текущий коннектор не гарантирован. Нельзя подменять их вручную; при невозможности загрузки это указывается
в разделе «Что не сделано».
