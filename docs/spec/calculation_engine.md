## Cash-flow (задача 13)

Денежные потоки в `cash_flows`: положительная сумма + `inflow/outflow`, план/факт, ссылка на версию обязательства или ручной источник. Окно `[первая дата, as_of]`; баланс на конец каждого календарного дня. Дефицитный день: баланс < 0. Максимальный разрыв — первое достижение абсолютного минимума. Финансирование [ОЦЕНКА]: `money(sum(abs(negative_eod_balance)) * rate / 365)`, одна ставка на окно (`--rate` либо датированный KEY_RATE на as_of). Вне горизонта — отдельный план; нет дат затрат/аванса/возврата удержания → «нет данных», автоматическое распределение запрещено. Повторный build защищён уникальным частичным индексом; новые версии обязательств supersede старые автопотоки.

## What-if

`whatif` — read-only; точка, чувствительность ±step и замкнутый обратный счёт прибыли. Все сценарии переиспользуют `apply_cost_scenario`, `scenario_revenue`, `scenario_financial_share`, `summarize_costs`, `calculate_profit` и `breakeven_net`. Множители не затрагивают финансовые статьи; доля финансовых расходов добавляется к фиксированным. `goal-seek` округляет m* до шести знаков и повторно проверяет прибыль, явно выводя остаток. `schedule_shift_days` не поддерживается, пока нет календарного пересчёта.


## Приём документов и вердикт (INGESTION-1)

Команда intake определяет тип файла по структуре XLSX, вызывает существующие импортёры и выдаёт квитанцию JSON/stdout. Повтор того же sha256 возвращает skipped без новых строк; ошибочный файл не останавливает пачку. XML GGE до получения официальной XSD не импортируется; docx/pdf не читаются.

Вердикт — read-only. Сетка снижения цены: gross(k)=Σ money(amount_gross_i×(1−k)) (позиционное округление); net(k)=money(gross(k)/(1+VAT_RATE(date))) (объектный сплит); VAT=gross−net; Δnet=net(k)−net(0). Сетка: 0, 5, 8, 10, 15, 20, 22%, плюс договорной фактор. Полнота сравнивает активные затраты с 29 статьями; шесть нормативных рисков выделяются без вымышленных сумм. Светофор по ADR-0017: маржа прибыли до налога ≥10% / ≥3% / <3%; без затрат не показывается. При договорном снижении прибыль пересчитывается с неизменными подтверждёнными затратами.
