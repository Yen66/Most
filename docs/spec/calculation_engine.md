# Спецификация расчётного ядра

| Показатель | Формула | Источник | Статус |
|---|---|---|---|
| Выручка с/без НДС | существующее ядро выручки | ВОР + `reference_rates/VAT_RATE` | реализовано |
| Себестоимость производственная | `direct + indirect + other` | актуальные `cost_entries` | реализовано |
| Финансовые расходы | `fixed + R × share` | `cost_entries` category financial | реализовано |
| Прибыль до налога | `R - total_costs(R)` | расчёт | реализовано |
| Налог на прибыль | положительная прибыль × `reference_rates/PROFIT_TAX` | справочник ставок | реализовано |
| Чистая прибыль | прибыль до налога − округлённый налог | расчёт | реализовано |
| Маржа | прибыль до налога / R | расчёт | реализовано |
| Точка безубыточности | `(production + financial_fixed)/(1-financial_share)` | расчёт | реализовано |
| Минимальная цена | `(production + financial_fixed)/(1-m-financial_share)` | расчёт | реализовано |
| Сценарии | параметры C5; financial не умножается cost_multiplier | `scenarios/scenario_params` | реализовано |
| Зимнее удорожание | параметр сценария или `WINTER_SURCHARGE`; без ставки число не выдумывается | график + справочник | реализовано частично: пользовательский параметр |
| Cash-flow / план-факт / BIM | — | — | не реализовано |
