# Construction OS

Детерминированный фундамент системы расчёта экономики дорожного/мостового объекта.

## Принципы

- деньги считаются только через `Decimal`;
- неизвестные значения не заменяются нулями;
- каждое внешнее значение хранит происхождение;
- расчётный слой не зависит от БД и ввода-вывода;
- история значений сохраняется через supersede;
- реальные документы не коммитятся, только обезличенные тестовые фикстуры.

## Текущий этап

Импорт ВОР и календарного графика, сверка, НДС и выручка. Себестоимость, прибыль, cash-flow,
план-факт, BIM и экспорт GGE сознательно не входят в этот фундамент.
